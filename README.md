# Synthetic Study Hours and Exam Scores

## Overview

This BDA400 project demonstrates clear documentation for a small R analysis. One script imports a synthetic dataset, validates its contents, summarizes two numeric variables, and exports a scatterplot. The data contain **30 invented records** and no real student information.

The values were chosen to illustrate an association between study hours and exam scores. They are not a random sample, a fitted research model, or evidence of causation. Results must not be generalized to real students.

## Installation

- Use R with RStudio or Posit Cloud.
- The analysis uses only standard R packages; no additional analysis packages are required.
- To knit the documentation to HTML, install `rmarkdown` and `knitr` once. A working Pandoc installation is also needed; RStudio normally supplies it.

```r
install.packages(c("rmarkdown", "knitr"))
```

Download or extract the project folder. In RStudio, create/open a project in that folder so the working directory contains `README.md`, `data/`, and `scripts/`. Keep the folder structure intact.

## Data

Input: [`data/synthetic_study_data.csv`](data/synthetic_study_data.csv).

| Column | Type | Definition |
| --- | --- | --- |
| `student_id` | Text | Invented unique identifier, S001 through S030 |
| `study_hours` | Numeric | Hours studied in the week before the fictional exam |
| `exam_score` | Numeric | Fictional exam score out of 100 |

All records were invented by ChatGPT for this exercise. No real data were uploaded. The CSV begins with ordinary column headers to remain compatible with R and spreadsheet imports; this declaration also covers its provenance.

## Validation and Troubleshooting

The script rejects empty input, unexpected columns, missing values, duplicate or invalid IDs, nonnumeric measurements, nonfinite values, hours outside 0-168, and scores outside 0-100. It creates `outputs/` when needed.

If an input-file error appears, run `getwd()` and confirm that `data/synthetic_study_data.csv` exists relative to that directory. If knitting reports a missing package, install the documentation packages above. Check output-directory write permissions if exports fail.
